# Консольная визуальная новелла

Учебный проект по курсу **Python и основы CS**. Индивидуальное консольное приложение для управления интерактивным сюжетом, персонажами и игровым процессом.



#  Основные возможности
1. **Интерактивный сюжет:** Прохождение истории на основе выбора вариантов ответа, загружаемых из внешнего файла.
2. **Собственный поиск:** Линейный поиск сцен по ключевым словам в тексте (`O(N)`).
3. **Собственная сортировка:** Сортировка персонажей методом пузырька (`O(N^2)`) по очкам симпатии.
4. **ООП и Полиморфизм:** Использование классов, композиции, датаклассов (`dataclass`) и полиморфных методов взаимодействия (`interact`).
5. **Поток данных:** 
   - Импорт начальных данных сцен из **CSV** (с валидацией и обработкой ошибок).
   - Сохранение и загрузка игрового прогресса в **JSON** для продолжения после перезапуска.
   - Ленивая обработка данных через генераторы.


# Структура проекта
Проект разделен на 4 ключевых модуля для соблюдения архитектурных требований:
* `main.py` — Точка входа, главный игровой цикл и управление состоянием.
* `models.py` — Описание классов (`Character`, `Scene`, `GameItem`, `GameSession`), а также алгоритмов поиска и сортировки.
* `storage.py` — Работа с файлами: импорт из CSV, генераторы, экспорт/импорт сохранений в JSON.
* `ui.py` — Пользовательский интерфейс, консольное меню и вывод информации.
* `data/scenes.csv` — База данных сюжета.
* `data/save.json` — Файл сохранения прогресса.


# Инструкция по запуску

1. Убедитесь, что у вас установлен **Python** (версии 3.8 или выше).
2. Клонируйте или скопируйте проект в отдельную папку на вашем ноутбуке.
3. Убедитесь, что структура папок выглядит следующим образом:
   
   visual_novel/
   ├── main.py
   ├── models.py
   ├── storage.py
   ├── ui.py
   └── data/
       └── scenes.csv
